Untamed
A long-term personal website: a private library and diary of poems, articles, and other writing, added to over a lifetime.
Purpose
Untamed is a place to keep my thoughts. It is not built to reach an audience. Nothing here is written for readers, and nothing needs to be fancy.
What it holds
Poems
Articles
Other writing, added as it is written
Entries accumulate over time. Nothing is removed for being old, and nothing is organised for publication.
Status
Ongoing. This is a long-term project and will grow indefinitely.
